# 🛒 SmartShop AI

## Cloud-Based E-Commerce Recommendation System

SmartShop AI is a machine learning based product recommendation system that recommends similar products based on product category and description.

### 🚀 Features

- Product-based recommendations
- TF-IDF text vectorization
- Cosine similarity
- Interactive Streamlit web application
- Product price and rating display
- Cloud deployment using Streamlit Community Cloud

### 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- TF-IDF
- Cosine Similarity

### ⚙️ How It Works

User selects a product → Product information is processed → TF-IDF converts text into numerical vectors → Cosine similarity calculates product similarity → Similar products are recommended.

### 📂 Project Files

- `app.py` – Streamlit web application
- `recommender.py` – Recommendation logic
- `products.csv` – Product dataset
- `requirements.txt` – Required Python libraries

### 🌐 Deployment

The application is deployed using **Streamlit Community Cloud**.
